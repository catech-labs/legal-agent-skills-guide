# Security Policy

This repository is a guide. It does not execute or redistribute the listed legal skills.

## Reporting an issue

Report issues involving:

- a malicious or compromised listed repository;
- prompt injection;
- credential or secret exposure;
- unsafe installation instructions;
- dependency compromise;
- hidden executable content;
- misleading data-handling claims;
- a material legal-source freshness problem.

Open a private security advisory for sensitive reports when available. Do not include client documents, privileged material, credentials, personal data, or confidential matter information.

## Scope

Listing a project is not a security approval. Users remain responsible for reviewing code, permissions, data flows, licenses, connectors, and legal suitability before use.
