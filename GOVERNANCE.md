# Governance

## Purpose

The Legal Agent Skills Guide is maintained as an independent, evidence-based map of open legal Agent Skills projects.

## Maintainers

Catech Labs is the initial maintainer. Code ownership is defined in `.github/CODEOWNERS`.

## Decision principles

Project decisions prioritize:

1. factual accuracy;
2. primary-source evidence;
3. transparent limitations;
4. jurisdiction awareness;
5. security and confidentiality;
6. licensing clarity;
7. reproducible evaluation;
8. independence from popularity metrics.

Stars, forks, sponsorships, commercial relationships, or vendor size do not independently determine inclusion or ranking.

## Changes to recommendations

A recommendation may change when there is material evidence involving:

- scope or jurisdiction coverage;
- maintenance status;
- licensing;
- security posture;
- data handling;
- installation model;
- documented evaluation results;
- project archival, compromise, or ownership change.

Material recommendation changes should update the English README, Portuguese README, structured catalog, and changelog.

## Conflicts of interest

Contributors should disclose employment, investment, advisory, commercial, or authorship relationships with projects they propose or evaluate.

## Releases

Public guide versions use semantic versioning:

- patch: factual corrections and minor documentation improvements;
- minor: new projects, categories, evaluation dimensions, or material recommendation updates;
- major: methodology or governance changes that alter how projects are evaluated.
