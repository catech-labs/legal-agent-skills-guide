# Support

This repository is a public research and curation guide.

## Questions about this guide

Use GitHub Issues for:

- factual corrections;
- broken links;
- project suggestions;
- methodology questions;
- missing jurisdictions or workflow categories;
- documentation improvements.

Before opening an issue, search existing issues and include the repository URL, the date checked, and evidence supporting the proposed change.

## Questions about listed projects

Installation failures, runtime problems, licensing questions, and project-specific behavior should be reported to the original project's maintainers. This guide does not maintain or provide support for third-party skills.

## Security reports

Follow [SECURITY.md](SECURITY.md). Never attach client documents, privileged information, credentials, personal data, or confidential matter information.

## Commercial support

This repository does not create a support obligation, service-level agreement, or warranty from Catech Labs.
